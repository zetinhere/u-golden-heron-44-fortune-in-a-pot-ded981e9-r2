One kind, funny fortune for the houseplant on the windowsill — a single line of at most 120 characters, written as a prediction about the plant's own future. A round-2 rebuild: the program was written, run, then genuinely revised (the fortune was reworded to name *this windowsill*, and the run was made warning-free) before bundling.

The fortune it writes:

> By spring you will outgrow this pot, and your keeper will finally admit this windowsill was your idea all along.

112 characters, one line, kind and warm to plant and keeper, with a small joke that lands instead of a groaned pun.

## Run it

```sh
node main.ts
```

Writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validating first that it is 1–120 characters and a single clean line, and leaving the file readable by every user (mode 0644).
